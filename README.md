# expense-tracker-backend (Ledgerly Tracker API)

<p align="center">Enterprise-grade REST API for personal financial management, built with Spring Boot 3 and PostgreSQL. Provides JWT authentication, transaction management, budgets, categories, transaction analysis, and monthly PDF reports.</p>

## 🚀 Installation

```bash
git clone https://github.com/RishabhDimri/expense-tracker-backend.git
cd expense-tracker-backend
mvn clean install
```

## 💻 Usage

```bash
mvn spring-boot:run
```

## ✨ Features

- ✅ JWT-based authentication
- ✅ User registration and login
- ✅ Access and refresh token support
- ✅ Password management
- ✅ Transaction management
- ✅ Income and expense tracking
- ✅ Transaction analysis
- ✅ Category management
- ✅ Custom categories
- ✅ Monthly category-based budgets
- ✅ Budget management
- ✅ Monthly financial reports
- ✅ PDF statement generation
- ✅ Pagination and sorting
- ✅ OpenAPI 3.1 documentation
- ✅ Interactive Swagger UI
- ✅ PostgreSQL persistence
